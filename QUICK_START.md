# 🚀 FinSync Quick Start Guide

## ⚡ 5-Minute Setup

### 1. Install Dependencies
```bash
npm install
```

### 2. Create `.env.local`
```env
VITE_SUPABASE_URL=https://nvaagwxwseiwcxdzhxzj.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
GEMINI_API_KEY=your-gemini-key
```

### 3. Run Database Schema
- Open: https://supabase.com/dashboard/project/nvaagwxwseiwcxdzhxzj/sql
- Copy `database.sql` → Paste → Run

### 4. Start App
```bash
npm run dev
```

### 5. Open Browser
http://localhost:5173
